# 🎖️ 밀리핏 트래커 (MiliFit Tracker)
> **육군 3대 체력검정 및 체급 통합 점진적 과부하 대시보드**  
> 3km 뜀걸음, 팔굽혀펴기, 윗몸일으키기 3대 종목과 체중 변화를 체계적으로 기록하고, 성장 차트 및 육군 공식 기준표와 대조하여 구글 스프레드시트에 실시간 연동합니다.

---

## 🚀 주요 기능 및 핵심 특징

### 1. 3대 종목 & 체급 통합 기록
- **측정 항목**:
  - **3km 뜀걸음**: 분/초 단위 정밀 기록 (자동 초 환산)
  - **팔굽혀펴기**: 2분 측정 횟수
  - **윗몸일으키기**: 2분 측정 횟수
  - **현재 체중**: 소수점 1자리(kg) 지원 (예: 88.0kg)
  - **훈련 메모 / 컨디션**: 러닝 페이스, 야간 측정, 식단 등 자유 기록
- **실시간 프리뷰**: 입력창에서 숫자를 입력하는 즉시 해당 기록의 등급 및 특급까지 남은 수치가 실시간 계산되어 미리보기 박스에 표시됩니다.

### 2. 최상단 실시간 특급 달성 타겟 브리핑 배너
- 최신 기록을 바탕으로 **국방부 부대관리훈령 별표 31** 기준표와 즉각 대조합니다.
- **하이라이트 헤드라인 문구**:
  > *"현재 2급입니다. 특급까지 팔굽혀펴기 8개, 뜀걸음 30초 단축이 필요합니다."*
- 특급전사 달성률(%) 게이지 프로그레스 바 및 종목별 특급 달성 뱃지 실시간 출력.
- 모든 종목 특급 달성 시 화려한 폭죽(Confetti) 효과와 함께 특급전사 인증 메시지가 표출됩니다.

### 3. 통일된 우상향 성장 차트 시각화
- **점진적 과부하 통합 차트**:
  - **3km 뜀걸음 축 반전(상향)**: 축 반전(`reverse: true`) 기법을 적용하여 시간이 단축될수록(기록이 좋아질수록) 그래프 곡선이 위로 올라가는 **우상향 곡선**을 그립니다.
  - **맨몸운동(팔굽혀펴기/윗몸일으키기)**: 횟수 증가에 따라 우상향 곡선 형성.
  - 모든 종목이 성장할수록 일관되게 우상향하여 시각적 성취감을 극대화합니다.
- **깔끔한 기본 초기 상태**:
  - 첫 실행 시 예시 지표 없이 빈 상태로 시작하며, 사용자가 직접 입력한 기록만으로 그래프가 구축됩니다 (필요 시 표 우측의 '8주 샘플 복원' 버튼으로 데모 확인 가능).

### 4. 육군 체력검정 공식 기준표 완벽 탑재
- 남군 / 여군 탭 전환 및 연령대(만 25세 이하, 26~30세, 31~35세, 36~40세, 41~45세, 46~50세, 51세 이상) 지원
- 현재 사용자의 성별 및 연령대 행이 황금색으로 자동 하이라이트됩니다.

### 5. 구글 스프레드시트(Google Sheets) 실시간 연동
- 구글 계정만 있으면 **복잡한 서버나 유료 API 키 없이 1분 만에 연동** 가능 (Google Apps Script Web App 방식).
- 기록을 추가하면 브라우저 로컬 저장소(LocalStorage)와 구글 시트에 동시에 안전하게 기록됩니다.
- [원클릭 스크립트 복사], [연동 테스트], [로컬 전체 기록 구글 시트로 일괄 업로드], [구글 시트에서 기록 가져오기(양방향)] 지원.

## 💻 실행 방법

별도의 Node.js나 Python 서버 설치 없이, 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 바로 사용하실 수 있습니다.

1. 프로젝트 폴더 내 **`index.html`** 파일을 더블 클릭하여 웹 브라우저로 엽니다.
2. 상단 메뉴에서 본인의 **[성별]**과 **[연령대]**를 선택합니다.
3. 기본적으로 탑재된 **8주 점진적 과부하 샘플 데이터**를 확인하거나, 우측 상단 **[새 기록 입력]** 버튼을 눌러 오늘 측정한 본인의 기록을 입력해보세요!

## 📊 구글 스프레드시트 연동 방법 (1분 소요)

1. 구글 드라이브(https://drive.google.com)에서 **새 스프레드시트**를 하나 생성합니다. (이름: `밀리핏_체력기록`)
2. 스프레드시트 상단 메뉴에서 **[확장 프로그램]** &rarr; **[Apps Script]**를 클릭합니다.
3. 프로젝트 내 `google-apps-script.js` 파일의 내용(또는 웹 대시보드 내 [구글 시트 연동 설정] 모달의 '코드 복사하기' 버튼 클릭)을 복사하여 기존 에디터 내용에 덮어씌웁니다.
4. 키보드의 **Ctrl + S**를 눌러 저장합니다.
5. 우측 상단 파란색 **[배포]** &rarr; **[새 배포]** 버튼을 클릭합니다.
   - 톱니바퀴 아이콘 클릭 &rarr; **웹 앱(Web App)** 선택
   - 설명: `밀리핏 API`
   - 다음 사용자 권한으로 실행: `나 (your-email@gmail.com)`
   - **액세스 권한이 있는 사용자**: 반드시 **[모든 사용자(Anyone)]** 로 선택!
6. **[배포]** 버튼을 누르고 화면에 나타나는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 밀리핏 웹 대시보드의 **[구글 시트 미연동]** 버튼을 눌러 복사한 URL을 붙여넣고 **[연동 테스트]** &rarr; **[URL 저장 완료]**를 누르면 연동이 끝납니다!

## 📁 파일 구성 안내

- `index.html`: 메인 웹 대시보드 인터페이스
- `css/style.css`: 택티컬 & 밀리터리 다크 모드 스타일시트
- `js/standards.js`: 국방부 부대관리훈령 별표 31 기준표 및 등급 판정 엔진
- `js/charts.js`: Chart.js 기반 우상향 성장 차트 및 상관관계 분석 시각화 엔진
- `js/store.js`: 로컬 스토리지 데이터 관리 및 8주 샘플 데이터 생성기
- `js/sheets.js`: 구글 스프레드시트 웹앱 통신 및 동기화 모듈
- `js/app.js`: 메인 컨트롤러 및 이벤트 처리
- `google-apps-script.js`: 구글 스프레드시트에 배포할 Apps Script 원본 코드

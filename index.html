클라우드 데이터베이스 연동

Vercel 배포용 Supabase 또는 구글 스프레드시트와 실시간 연동합니다.

Supabase 1분 연동 3단계
  1. supabase.com 가입/로그인 후 [New Project] 생성
  2. 좌측 메뉴 [SQL Editor] → [New Query]에 아래 테이블 생성 SQL 실행
  3. [Project Settings] → [API] 에서 Project URL과 anon public API key 복사 후 아래 입력
테이블 생성 SQL 
create table if not exists public.milifit_records (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  date text not null,
  weight numeric(4,1) not null,
  run_min integer not null,
  run_sec_only integer not null,
  run_sec integer not null,
  pushup integer not null,
  situp integer not null,
  overall_grade text,
  notes text
);
alter table public.milifit_records enable row level security;
create policy "Allow anon full access" on public.milifit_records for all to anon using (true) with check (true);
구글 시트 1분 연동 3단계
  1. 구글 드라이브에서 새 스프레드시트를 만듭니다.
  2. 상단 메뉴 [확장 프로그램] → [Apps Script]를 엽니다.
  3. Code.gs에 연동 코드를 넣고 [새 배포] → [웹 앱]으로 배포합니다.
  4. 발급된 웹 앱 URL을 아래 입력칸에 붙여넣고 [저장]하면 완료!
